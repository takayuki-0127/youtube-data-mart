## 1. SSMS で器を作る（5分）
1. SSMS で localhost に接続（証明書のエラーが出たら「暗号化なしで接続」）

## 2. Python の準備（初回だけ・10分）
PowerShell で（フォルダは youtube-data-mart）：
```
cd $HOME\Desktop\youtube-data-mart
python --version                 # 入っていなければ https://www.python.org から 3.12 を入れる（「Add to PATH」に✓）
pip install -r requirements.txt
Get-OdbcDriver | Where-Object Name -like "*SQL Server*" | Select-Object Name   # 「ODBC Driver 17/18 for SQL Server」があるか
copy .env.example .env           # 18 しかなければ .env の 17 を 18 に書き換える
```

## つまずきそうな所
- `Data source name not found` → ODBC ドライバ名が違う（.env の 17/18）
- `Login failed` → .env の trusted_connection=yes（Windows 認証）を確認
- `TRUNCATE` で `Cannot find the object` → 01_create_stg.sql を先に実行していない
- 日本語の列名で KeyError → CSV を Excel で開いて上書き保存していないか（文字コードが変わる）
