# 実験1：Shorts に「関連動画」リンクを付けると、長尺の視聴は増えるか（設計・2026-10-20）

## なぜこの要因か
- E の分析で、公開前にわかる要因（曜日・投稿間隔・タイトル）は予測にほとんど効かなかった（SHAP の寄与が小さい）。種類と長さは効くが、チャンネルの方針そのものなので「1か所だけ変える」実験に向かない
- Shorts → 長尺の分布ラグ回帰では、翌日〜7日後の合計 +10.8回（95%CI −7.4〜+29.0）で「はっきりした関連は見えない」。ただし今は **Shorts から長尺へ誘導する仕組みをほとんど使っていない**
  - 93日間のトラフィックソース：全 36,577回のうち「ショート フィード」30,315回（83%）に対し、「関連のショート動画」（Shorts に付けたリンクからの視聴）は **14回（1日 0.1回）**
- 「関連動画」リンクは Shorts ごとに自分で付け外しでき、費用もかからない。結果も「関連のショート動画」という専用の流入元で測れる

## 1枚の設計
| 項目 | 中身 |
|---|---|
| 仮説 | 新しい Shorts に、内容の近い長尺を「関連動画」として付けると、長尺の視聴が「関連のショート動画」経由で増え、長尺全体の1日の視聴も増える |
| 打ち手 | 期間中に出す **すべての新しい Shorts** に、テーマの近い長尺（再生上位12本から選ぶ）を「関連動画」で付ける。それ以外（投稿の本数・時間帯・タイトルの付け方）は今まで通りにする |
| 期間 | **4週間：2026-10-21（火）〜 11-17（月）**。データの取り出しは 11/24 ごろ（遅れて届く視聴を待つ）。まとめは 11月末 |
| 見る指標 | 主：長尺の「関連のショート動画」経由の視聴回数（1日あたり）。副：長尺の1日の視聴回数（全体 −「ショート フィード」−「関連のショート動画」、e_05 と同じ近似）・長尺の総再生時間 |
| 比べ方 | **前後比較**（直前の4週間 9/23〜10/20 と、期間中の4週間）。副の指標は e_05 と同じ回帰（曜日・トレンド・長尺の投稿本数をそろえ、Newey–West の標準誤差）に「リンク期間」の0/1を足して差を出す |
| 交互にしない理由 | リンクは一度付けると Shorts に残り続けるので、週ごとに ON/OFF を交互にすると前の週の影響が混ざる。そこで「期間中の新しい Shorts だけに付ける」前後比較にする |
| 判断の基準（先に決める） | 主の指標が 1日 0.1回 → **1日 3回以上**になれば「誘導の入口として使える」。副の指標の差の 95%CI が0をまたぐなら「長尺全体を押し上げるほどではない」と書く |
| 記録すること | Shorts ごとに：公開日時・付けた長尺のタイトル（記録用の表に1行ずつ）。期間中にサムネイルや長尺の公開方針を変えたら、その日をメモする |

## 前提と限界
- 前後比較なので、季節（クリスマス系の長尺が10月から伸び始めている、SQL 5問の Q2）やおすすめの波の影響は分けきれない。副の指標はトレンド項でならすが、原因とまでは言えない
- 4週間・1チャンネルの結果なので、ほかのチャンネルにそのまま当てはまるとは限らない
- クライアントの了承を待たずに回せる実績として、結果は youtube-data-mart の extras と note にまとめる
